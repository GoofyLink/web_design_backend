# 在线设计平台规划

版本：v0.1；日期：2026-11-26；状态：B1—B6、B8 后端接口已实现，双前端业务联调待完成。

目标：参考稿定设计的使用场景，建设用户网页版、管理员后台和 Go 后端。采用模块化单体，按功能分批交付。

| 文档 | 内容 |
| --- | --- |
| [PRD](./PRD.md) | 用户、页面、功能规则、产品边界、验收要求 |
| [后端技术方案](./TECHNICAL-DESIGN.md) | 单进程部署、模块划分、数据模型、接口约定、运行方式 |
| [分批开发计划](./DELIVERY-PLAN.md) | 每批的后端、用户端、管理端工作和验收门槛 |

已确定：Vue 用户端；Vben web-ele 管理端；Go + go-zero 模块化单体；先文档再开发，先接口后前端联调。

当前设计默认：MySQL 8 为必需外部服务，本地目录保存文件；初期无需 Redis、Kafka、etcd、独立 RPC 或 Docker。单 Go 二进制指一个后端业务进程，不代表不需要数据库。后期可替换对象存储。

编辑器候选：优先验证 yft-design 开源版本，vue-fabric-editor 为备选。最终选择以开源仓库的保存、恢复、导出和字体测试为准，不以商业演示作为能力保证。

已完成 B1—B6、B8 共 125 个后端端点，运行与联调说明见 [Design API README](../../app/design/README.md)。B7 会员支付按内部使用要求不开发。AI 服务配置与任务接口已实现，真实 AI 和批量渲染服务尚未接入；用户站和后台业务页面仍待接入。接口文档入口目前接在 Vben web-antd，规划原选 web-ele，正式后台版本需在前端实施时统一。当前本地数据库已使用 MySQL 5.7.26 验证，MySQL 8 尚未实测。
