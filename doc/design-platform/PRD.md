# 在线设计平台 PRD

实施更新（2026-11-26）：当前定位为公司内部使用，B7 会员支付排除；B5/B6/B8 后端接口已实现。AI 仅提供后台可配置接入，不连接真实服务商；前端页面和真实渲染验收仍待开发。

版本 v0.1 / 2026-11-26 / 待分批实施。

## 1. 产品目标与依据

为个人创作者、小商家和运营人员提供中文网页设计工具：找到模板，修改文字和图片，保存作品，下载成品。管理员能够持续上架模板、管理素材、维护专题并处理用户问题。

参考来源：

- 用户提供的 [稿定首页](https://www.gaoding.com/) 截图：可见创作、发现、我的、创建、登录注册；模板搜索、分类、热门话题；海报、小红书封面、公众号首图、直播贴片、商品主图、PPT；图片、视频、AI 等入口。
- 本次直接请求稿定网站返回浏览器验证页，未完成登录后流程和收费能力实测。以下业务规则是本项目设计，不代表稿定实际实现。
- [yft-design](https://github.com/dromara/yft-design) 和 [vue-fabric-editor](https://github.com/ikuaitu/vue-fabric-editor) 作为开源编辑器候选；[Vben Admin](https://github.com/vbenjs/vue-vben-admin) 作为管理后台。

产品参考功能和流程，采用自己的品牌、页面设计与有授权的素材。

## 2. 三端职责与角色

| 端 | 使用者 | 职责 |
| --- | --- | --- |
| 用户网页版 | 公司内部用户 | 浏览与搜索模板、在线编辑、管理作品、上传素材、导出 |
| 管理员后台 | 超级管理员、内容运营、客服 | 管理分类、模板、素材、专题、用户、权限和审计 |
| Go 后端 | 两个前端共用 | 身份与权限、业务校验、数据持久化、文件授权、任务与运营数据 |

游客可以浏览已发布模板及公开预览，使用模板时先登录；登录成功返回原模板。注册用户只能读写自己的作品和私有素材。内容运营能管理内容但不能授予权限；客服可以查询用户状态，不默认获得私有作品读取权。超级管理员分配角色。普通用户身份不能访问任何管理员接口。

## 4. 用户网页版信息架构

桌面浏览器优先支持最新 Chrome、Edge。移动端支持浏览、登录和作品列表；第一版复杂画布编辑提示使用电脑。

| 页面/建议路由 | 内容与操作 | 主要状态 |
| --- | --- | --- |
| 首页 `/` | 搜索、场景分类、精选模板、创建入口；B6 增加运营专题 | 加载、无内容、接口失败可重试 |
| 模板列表 `/templates` | 关键词、分类、尺寸比例筛选；最新/热门排序；分页 | 无结果保留筛选并可清空 |
| 模板详情 `/templates/:id` | 预览、标题、尺寸、标签、使用模板 | 下架或不存在统一提示不可用 |
| 登录/注册 `/login` `/register` | 用户名与密码；昵称可后补 | 校验、登录失败、频率限制、成功返回原页面 |
| 编辑器 `/editor/:designId` | 素材栏、画布、图层与属性、撤销重做、保存状态、导出 | 加载、未保存、保存中、已保存、断网、冲突 |
| 我的作品 `/workspace/designs` | 列表、搜索、改名、复制、删除、最近修改 | 空列表引导创建，删除确认 |
| 回收站 `/workspace/trash` | 恢复、彻底删除 | 第一版软删除保留 30 天，恢复和彻底删除由 B4 交付 |
| 我的素材 `/workspace/assets` | 上传图片、预览、删除 | 上传进度、超限、格式错误 |
| 账户 `/account` | 昵称、头像、修改密码、退出 | 保存成功/失败，密码修改后会话失效 |
| 收藏 `/workspace/favorites` | 收藏模板、取消收藏，B6 | 已下架模板标记失效 |
| 会员/订单 | 不在内部版范围 | 不展示入口 |

### 4.1 模板与首页

- 分类采用场景分类，例如海报、小红书封面、公众号首图、商品主图、直播贴片。PPT 类目在实际具备能力前不开放。
- 搜索范围为已发布模板的标题、标签、分类；初期 MySQL 查询，不要求智能推荐或以图搜图。
- 模板分页默认 20 条，最大 100；固定排序次序及 ID 作为次级排序，避免同时间数据跳动。
- 模板有独立封面和编辑数据。公开列表只提供封面；使用接口在鉴权后创建独立作品副本。
- 模板更新或下架不覆盖用户已创建的作品。下架后禁止新建引用，已有作品继续编辑。

### 4.2 编辑器与作品

- 第一版支持单页静态图片：文字、图片、基础形状、图层顺序、对齐、缩放、旋转、背景、撤销重做。
- 空白创建可选择预设尺寸或自定义尺寸；产品初始上限为单边 8192 像素且总像素不超过 4000 万，超限提示。
- 自动保存采用停止编辑后约 2 秒触发，允许手动保存；保存失败保留本地草稿，不显示已保存。
- 浏览器草稿按用户与作品隔离，提供清理入口；退出账号清理当前账号本机草稿，避免共用电脑泄露。
- 每次保存带服务端版本号。多个标签页或设备同时修改时返回冲突，不静默覆盖；用户可重新加载或另存副本。
- 作品 JSON 必须包含编辑器类型、编辑器版本、文档协议版本；后端作为版本化文档保存，不能任意混用不同编辑器数据。
- 字体、图片引用使用平台资源 ID，客户端加载编辑器时解析访问地址；不把短期签名 URL 作为永久文档内容。
- 撤销重做第一版在当前编辑会话内有效；服务端历史版本与恢复在 B6 增加。
- 删除作品进入回收站，列表默认排除；恢复时保留内容与名称。彻底删除需要确认，资源回收遵循引用关系。

### 4.3 上传与导出

- 用户图片上传第一版接收 JPEG、PNG、WebP，单文件不超过 20 MiB。后端检查真实类型、解码尺寸和额度，不仅检查扩展名。
- 初始用户存储额度 200 MiB，可配置。额度计入原始图片、作品 JSON、封面与持久化导出文件，不因软删除立即释放。
- 字体仅管理员上传和授权后发布，用户不开放字体上传。SVG、PSD、PDF 导入暂不作为首版承诺。
- 浏览器利用选定编辑器导出 PNG/JPEG；后端负责权限与资源访问，并记录导出事件。浏览器渲染失败不能记作成功。
- 透明背景只适用于 PNG；JPEG 使用用户选择的背景色。默认导出原始尺寸，倍率导出仍受像素上限约束。
- 首版不承诺后端 Go 原生渲染 Fabric 文档。服务器批量渲染需要额外浏览器渲染环境，独立放在 B8。

## 5. 管理员后台信息架构

基于现有 Vben `web-ele`，与用户站分开构建和登录，不共享用户端 Token。

| 菜单 | 功能 | 批次 |
| --- | --- | --- |
| 登录与个人资料 | 管理员账号密码登录、退出、密码修改 | B1 |
| 系统管理 | 管理员、角色、权限码、菜单；保留最后一个有效超级管理员 | B1 |
| 用户管理 | 查询、启用/禁用用户；禁用后立即拒绝已签发会话 | B1 |
| 分类管理 | 分类新增、编辑、排序、启用/停用 | B2 |
| 模板管理 | 草稿、预览、发布、下架、修改；封面、分类、标签与文档校验 | B2/B4 |
| 素材管理 | 公共图片、字体、授权说明、启停、引用查询 | B3 |
| 内容审计 | 谁在何时修改、发布、下架内容 | 各批累积 |
| 首页运营 | 专题、推荐位、排序、上线时间 | B6 |
| 数据概览 | 新增用户、作品创建、模板使用、成功导出；明确时间范围 | B6 |
| 商业管理 | 内部版不开发 | 已排除 |
| AI/任务管理 | 渠道配置、额度、任务状态与失败重试 | B8 |

模板状态为 `draft → published → offline`，下架后可以重新发布。编辑已发布模板产生草稿修订，重新发布前旧版本继续展示。已发布模板必须拥有可访问的封面、可恢复的文档和完整的资源引用。模板引用的素材停用前展示影响，已有作品使用的资源不能被物理删除。

管理端使用固定本地路由加服务端权限码；按钮隐藏只是交互，Go 接口必须独立校验权限。第一版不做任意配置前端组件路径的动态菜单搭建器。

## 6. 核心流程

1. 管理员创建分类 → 上传公共素材 → 创建模板草稿 → 编辑器验证预览 → 发布。
2. 游客进入首页 → 搜索 → 详情 → 登录 → 使用模板 → 获得个人作品 ID。
3. 用户编辑 → 上传个人图片 → 自动保存成功 → 重新进入可恢复相同内容。
4. 用户发起导出 → 检查资源和尺寸 → 浏览器生成图片 → 下载成功 → 上报带去重标识的导出事件。
5. 用户误删 → 回收站恢复；管理员下架模板 → 新用户不可继续套用，已保存作品不受覆盖。

## 7. 验收与质量

- 完成注册、登录、选模板、编辑、保存、刷新恢复、下载图片的端到端闭环。
- 管理员发布后用户站可发现；下架后搜索与详情按规则变化。
- 用户 A 无法读写用户 B 的作品、封面、私有上传文件；管理员普通查询不得绕过资源权限。
- 用户禁用、退出和修改密码后，会话按设计失效；密码不以明文或 MD5 保存。
- 保存冲突、文件超限、数据库故障都有稳定错误码与用户提示；失败不能产生“保存成功”假象。
- 后端重启后账号、模板、作品、素材元数据和磁盘文件仍可恢复；数据库与文件联合备份可还原。
- 初始性能验证目标：本机/测试服务器记录硬件与数据规模，在 1 万模板、20 并发下，列表与详情接口 P95 小于 500 ms，普通保存 P95 小于 1 秒；不含公网传输与浏览器渲染。这是测试目标，不是已达成结论。
- 首页、列表、详情提供语义化内容、标题、基础键盘操作；编辑器提供快捷键说明和清晰焦点。

## 8. 观察指标与后续决策

记录模板使用次数、作品创建量、保存成功率、版本冲突率、成功导出次数与活跃用户；导出事件按用户与事件 ID 去重，不用于计费凭证。

后续才需决定：正式品牌与域名、商用字体素材清单、短信或扫码登录渠道、AI 服务商及内容策略、服务器资源和对象存储。它们不阻塞 B1 开发。
