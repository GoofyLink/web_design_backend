# 按功能分批开发计划

每批遵循：确定契约与迁移 → Go 接口和测试 → 管理端接入 → 用户端接入 → 联调验收 → 更新文档。一个批次可以由多次开发会话完成；不一次性提交所有未完成菜单。

总体完成标准：接口能用真实数据验证，前端不能只返回 mock；迁移可重复检查；重启后数据不丢；本批权限负例通过；记录启动命令及已知限制。本文不承诺未经评估的工期。

| 批次 | Go 后端 | 用户网页版 | Vben 管理端 | 通过标准 |
| --- | --- | --- | --- | --- |
| B0 文档与编辑器验证 | 确定模块、部署与协议；当前先交付文档 | 验证编辑器 JSON 恢复、字体、图片及 PNG/JPEG 导出；确定实际可用开源版本 | 确认 web-ele 的登录、权限和响应适配点 | 文档齐全；编辑器验证完成后锁定引擎版本，验证失败再选备选 |
| B1 服务与身份 | 单 exe、配置、MySQL 迁移、健康检查、账号会话、RBAC、审计 | 基础站点壳、登录/注册、账户页、登录返回来源页 | 接入真实管理员登录、当前用户、权限码、管理员/角色和用户状态管理 | 两端分别登录；普通用户不能进入后台；退出/禁用立即失效；exe 重启账号仍存在 |

## 第一批拆成四次开发

### B1.1 可运行后端骨架

- 新建 app/design 入口和模块目录；保留现有民宿业务。
- 定义配置、日志、统一响应、参数校验和错误码。
- 引入 MySQL 迁移版本表，提供 migrate/serve 子命令；健康检查覆盖数据库和文件目录。
- 验证 Windows exe 构建与直接运行；文档记录数据库初始化步骤。
- 交付：可执行文件构建脚本、example 配置、迁移框架、健康接口和冒烟步骤。

### B1.2 用户身份接口与用户站基础页

- 用户与会话表；用户名密码注册登录；bcrypt、刷新旋转、退出、资料、修改密码。
- 用户站建立 Vue 3 + TypeScript 工程或独立应用壳；编辑器作为后续模块集成，不直接把 Vben 管理布局当用户首页。
- 登录注册与账户页接真实接口；统一 401 和字段错误反馈。
- 验收：重复用户名、错误密码、过期 token、旧 refresh token 重放、密码修改后旧会话失效。

### B1.3 管理员与权限

- 管理员、角色、权限关联表；交互式初始化管理员命令；管理端独立登录会话。
- 按 Vben 实际类型实现用户信息和权限码；修改管理端 baseURL、刷新字段和固定路由权限。
- 实现管理员、角色和用户状态页面，普通用户不具备后台入口。
- 验收：非管理员 token、无权限管理员、封禁用户与最后一位超级管理员保护。

### B1.4 联调与文档封版

- 两端登录与退出完整回归；数据库故障、参数错误、跨域凭据和刷新 cookie 验证。
- 输出 `.api`、OpenAPI、HTTP 请求样例、初始化与启动说明。
- 检查生产不依赖 mock、不带默认密码；完成重启持久化测试。
- 更新 B1 状态后开始 B2，不把未完成项标记完成。

## 批次依赖说明

- B2 可以使用少量自制/授权的种子模板和静态封面验证目录接口；正式上传依赖 B3，编辑生成模板依赖 B4，因此 B2 不宣称模板全流程已经完成。
- B4 前必须完成 B0 编辑器验证并记录版本、序列化格式与资源引用规则；B1 的身份接口可以先行。
- B4 的作品封面仅满足基础列表；B5 完善编辑后重新生成和替换封面，失败不覆盖最后有效封面。
- B5 是第一个可以供真实用户完成设计闭环的版本，B1/B2 只是阶段能力。
- B7 已排除。B8 先完成后台可配置的服务商与任务接口，不接真实 AI；真实厂商及受信渲染环境需后续配置和验收。
