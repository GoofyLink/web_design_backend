# go-zero-looklook 初学者开发指南

这份指南帮助你理解项目结构，在 Windows 上运行用户中心，并沿着真实请求学习 API、RPC 和数据库访问。完成入门流程后，你应当能注册用户、登录、查询当前用户信息，并知道新增接口时需要修改哪些文件。

适用读者：了解 Go 基础语法，使用过 HTTP 和 SQL，但尚未开发过 go-zero 微服务的开发者。

## 开始阅读

按顺序完成前四篇。遇到错误时，查阅排错参考。

| 文档 | 你将完成的任务 |
| --- | --- |
| [认识项目结构](01-认识项目结构.md) | 区分框架、业务服务和基础设施，找到代码入口 |
| [运行用户中心](02-运行用户中心.md) | 启动 MySQL、Redis 和两个 Go 进程，完成接口验证 |
| [跟踪请求和业务流程](03-跟踪请求和业务流程.md) | 理解注册、鉴权、事务、缓存、订单和消息队列 |
| [开发和验证接口](04-开发和验证接口.md) | 添加一个练习接口，掌握代码生成与验证步骤 |
| [配置与排错参考](05-配置与排错参考.md) | 查询地址和端口，处理启动、鉴权与生成代码问题 |
| [登录接口调用链源码对照](06-登录接口调用链源码对照.md) | 逐文件跟踪登录请求，定位参数转换、网络调用、SQL、密码校验和响应返回 |

第一次学习只需要 MySQL、Redis、`usercenter-rpc` 和 `usercenter-api`。Kafka、微信支付、日志平台和 Kubernetes 可以在完成用户中心流程后再学习。

## 命令与路径约定

除非步骤另有说明，命令在 Windows PowerShell 中执行，起始目录为：

```powershell
Set-Location E:\go\go-zero-looklook-main
```

正文中的 `app/...`、`pkg/...`、`deploy/...` 都相对于项目根目录。文档中的源码链接采用当前机器的绝对路径；复制项目到其他目录后，可以按链接标签中的相对路径查找文件。

`powershell` 代码块用于宿主机，`sql` 代码块用于 MySQL 客户端，`yaml` 代码块用于配置文件。不要把 SQL 直接粘贴到 PowerShell。命令不带 `$` 提示符，以便复制。
