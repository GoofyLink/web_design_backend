# 内部使用版 B5 / B6 / B8 接口

会员、订单、支付、退款均不在当前范围。所有用户端接口使用用户 Bearer，管理员接口使用独立管理员 Bearer；所有权不匹配返回 404。完整请求 schema 见 openapi.json，成功响应仍为 `{code:0,message:"ok",data,requestId}`。

## B5 导出、封面和异常

| 方法与路径 | 请求 / 行为 |
| --- | --- |
| POST /api/v1/designs/:id/export-check | `{version,format:"png或jpeg",scale:1至4}`，校验当前版本、资源引用和像素上限 |
| POST /api/v1/export-events | `{eventId,checkId,status:"succeeded或failed",errorCode?}`，记录客户端结果 |
| POST /api/v1/designs/:id/cover | `{version,assetId}`，使用已上传、可访问的图片替换封面，成功返回 `{id,version}` |
| GET /api/admin/v1/export-events | operation:read；分页及 status 筛选，返回导出版本、格式、用户 ID、错误码和时间 |
| GET /api/admin/v1/statistics | operation:read；from/to 为 RFC3339，默认最近 30 天，最多 366 天 |

export-check 返回 `{checkId,designId,version,format,width,height,expiresAt,renderMode:"browser",watermark:false}`。有效期 10 分钟，单边不超过 8192，总像素不超过 4000 万；不渲染、不返回图片下载地址。前端须完成字体加载、Canvas PNG/JPEG 导出，再回报结果。此接口不限制会员权益。

eventId 为 8—100 位字母、数字、点、下划线、冒号或连字符；同用户同 ID 同参数可重试，不同参数返回 409。一个 checkId 只能记录一次终态；过期检查不可首次上报。errorCode 仅允许上述 ASCII 字符，最多 64 位；成功事件必须为空。不要传完整异常堆栈、作品内容或密钥。事件代表客户端报告，不是服务端验证下载成功。统计采用 UTC、时间区间 `[from,to)`；用户/作品/模板/收藏为当前总量，导出数和 dailyExportsUTC 为区间统计，无事件的日期不补零。

封面更新必须先上传成功，再调用 cover；失败保留旧封面和版本。上传成功但未采用的图片仍在个人素材库，可自行删除。封面更新也保留上一份文档历史。

配置 SiteDir、AdminDir 后，exe 可以分别托管构建好的用户站和后台；默认空值，不托管任何目录。用户站 fallback 到 index.html，后台路径为 /admin/；API 不参与 SPA fallback。后台前端构建时需要 base=/admin/。本次没有构建 Vue 页面，也未进行浏览器像素和导出验收。

## B6 收藏、文件夹、历史、专题

| 方法与路径（用户前缀 /api/v1） | 请求 / 响应 |
| --- | --- |
| PUT /favorites/:id | 收藏已发布模板；重复调用不重复添加 |
| DELETE /favorites/:id | 取消收藏，幂等 |
| GET /favorites | 分页，仅返回当前仍发布且分类启用的模板 |
| GET /folders | `[{id,name,version,count}]`，最多 200 个；count 不含回收站作品 |
| POST /folders | `{name}` → `{id,version:1}` |
| PUT /folders/:id | `{version,name}` → `{id,version}` |
| DELETE /folders/:id | `{version}`，仅删除归属关系，保留作品 |
| GET /folders/:id/designs | 分页返回 `{id,title,version}` |
| PUT /designs/:id/folder | `{version,folderId}`；空字符串表示移出；成功作品 version +1 |
| GET /designs/:id/history | 最近 20 个旧文档 `[{id,version,createdAt}]`，不分页 |
| GET /designs/:id/history/:historyId | `{id,version,content,createdAt}` |
| POST /designs/:id/history/:historyId/restore | `{version}` 为作品当前版本；历史内容恢复为新版本，返回 `{id,version}` |
| GET /topics | 公共专题分页，支持 keyword、slot=home/featured |
| GET /topics/:id | 公共专题详情及有序模板 |

每次文档保存、封面替换或历史恢复，在同一事务保存修改前的文档和资源引用；只保留最近 20 份。改名、移动文件夹不产生内容快照，因此历史版本号不一定连续。历史不恢复标题、文件夹或删除状态；只恢复 Content。旧版数据库升级前的修改无法补录。

历史 Content 字节计入存储额度；素材被旧历史引用时也禁止删除。超出 20 份时原子清理最旧快照及引用，永久清除作品时释放全部历史。恢复同样检查当前版本和引用权限，不会盲目覆盖最新保存。回收站期间不能读取/恢复历史，先恢复作品。

管理端 `/api/admin/v1/topics`：GET 列表、GET /:id 需要 operation:read；POST、PUT /:id、DELETE /:id 需要 operation:write。POST/PUT 输入：

```json
{
  "title": "公司常用海报",
  "description": "内部模板推荐",
  "status": "published",
  "slot": "home",
  "sort": 10,
  "startsAt": "2026-11-01T00:00:00Z",
  "endsAt": "2027-12-31T00:00:00Z",
  "templateIds": ["1", "2"],
  "version": 1
}
```

创建无需 version，更新必须匹配当前 version；成功 `{id,version}`。title 最多 100 字、description 最多 2000 字、模板最多 100 个且不可重复。status=draft/published/offline；slot 为空、home 或 featured；sort 升序，模板顺序取 templateIds 顺序。发布至少一个模板，且都已发布、分类启用。

公开查询仅展示 published 且 `startsAt <= 当前 UTC < endsAt` 的专题，详情动态排除下架模板；首页 GET /home 追加 topics，取 slot=home 的前 12 个生效专题。修改 status=offline 即下线；DELETE body `{version}`，已发布专题必须先下线。专题删除不删除模板。

## B8 服务商配置（当前不接真实服务）

新数据库不带默认服务商、密钥或额度，不会自动调用 AI。后台配置接口已实现，Vue 管理页面尚未开发。管理员需要显式录入、启用服务商并给用户分配额度，任务才会运行。

| 方法与路径（管理前缀 /api/admin/v1） | 权限与行为 |
| --- | --- |
| GET /providers | provider:write；配置列表，最多 100 个，密钥只返回 hasKey |
| POST /providers | provider:write；新增配置 → `{id,version}` |
| PUT /providers/:id | provider:write；按版本更新配置或启停 |
| GET /users/:id/task-quota | job:read；读取额度 |
| PUT /users/:id/task-quota | job:write；`{limitUnits}` 设置累计总额度 |
| GET /jobs、GET /jobs/:id | job:read；全局任务元信息，不含提示词、文档或私有输出 |
| GET /jobs/:id/attempts | job:read；最近 100 次尝试状态、错误码与时间 |
| POST /jobs/:id/cancel | job:write；取消排队/运行中的任务 |
| POST /jobs/:id/retry | job:write；重试失败任务，重新预留额度 |

服务商 POST/PUT 请求：

```json
{
  "name": "公司图片服务",
  "kind": "image",
  "endpoint": "https://your-provider.example/v1/images/generations",
  "model": "your-image-model",
  "apiKey": "仅写入，不会回显",
  "status": "disabled",
  "version": 1
}
```

kind=image/renderer；status=active/disabled。endpoint 为完整 POST URL，不是 baseURL，禁止 URL 凭据、query、fragment。image 需要 model 和已配置密钥才能创建任务；renderer 的 model 可省略。创建无需 version；更新必须携带当前版本。apiKey 省略/空值保持旧密钥；clearKey=true 清除，不能与新 apiKey 同时传。密钥以 AES-GCM 加密存储，密钥派生自服务 JWTSecret；须安全备份并保持该密钥稳定，直接更换后需重新配置服务商密钥。日志和审计不记录密钥正文。

有 queued/running 任务时不能修改服务商 kind、endpoint、model，可停用或轮换密钥。停用后不再发出新的项目请求，已发送的 HTTP 调用无法保证远端取消。

默认仅 HTTPS，网络连接解析后拦截私网、环回、链路本地等地址，不跟随重定向、不自动使用代理环境变量。公司自建渲染服务如确需私网 HTTP，运维明确设置 `AllowPrivateProviders: true`；该开关不会自动启用任何服务商。provider:write 是能配置外发地址和凭据的高权限，应仅授予可信管理员。

## B8 用户任务与额度

| 方法与路径（用户前缀 /api/v1） | 行为 |
| --- | --- |
| GET /job-capabilities | 当前启用且可用的服务商 ID/名称/类型/模型；不返回地址/密钥 |
| GET /task-quota | `{limitUnits,reservedUnits,consumedUnits,availableUnits}` |
| POST /jobs | 创建任务，必须有 Idempotency-Key |
| GET /jobs | 当前用户任务分页，支持 status |
| GET /jobs/:id | 任务详情、completedItems/totalItems、results 素材元数据 |
| POST /jobs/:id/cancel | 取消 queued/running；重复取消已取消任务幂等 |
| POST /jobs/:id/retry | 重试 failed；不能重试成功/取消/未完成任务 |
| DELETE /jobs/:id | 删除已结束任务；释放快照空间与引用，输出文件保留在我的素材 |
| GET /jobs/:id/download | 成功 batch-export 任务输出 ZIP，需 Bearer；其他任务返回 409 |

图片任务请求：

```json
{"providerId":"1","kind":"ai-image","prompt":"公司内部海报背景","size":1024}
```

提示词 1—2000 字，size 为 256/512/1024，每次一张。适配 OpenAI 兼容图片生成接口，发送 model/prompt/size/n=1/response_format=b64_json；只接受 `data[0].b64_json`，不抓取服务商返回的任意 URL。返回图片必须是符合尺寸的有效 PNG。各厂商参数和模型差异需接入时实测，目前没有连接真实厂商。

批量任务请求：

```json
{"providerId":"2","kind":"batch-export","format":"png","items":[{"designId":"10","version":3},{"designId":"11","version":7}]}
```

每次 1—10 个自己的非回收站作品，format=png/jpeg，version 必须匹配。创建时保存独立文档快照、资源引用；之后源作品修改/删除不改变任务输入。所有文档快照合计最多 5 MiB，单个渲染项目资源原始字节最多 20 MiB。服务端只传资源 ID 文档及内联文件内容，不传用户 Bearer/ticket。结果逐项保存为私有素材，ZIP 在下载时生成。

任务幂等键要求与作品一致，但有效期为任务记录存在期间；同用户同键相同参数返回原任务，不同参数 409。删除记录后重用键会创建新任务。任务上限为每用户同时 10 个 queued/running。默认额度为 0，需要管理员分配；图片每张 1 单位，批量每个作品 1 单位。这是内部调度预算，不是货币、会员或服务商实际账单。

创建原子预留，完全成功才转为 consumed；终态失败/取消返还整个任务预留。部分完成的素材仍保留并占磁盘额度，任务删除后可在素材库删除。重试重新预留，已落库结果复用，不重复生成已有项目。任务快照也计入存储额度；任务保留期间其输入和输出资源不能删除。

## B8 队列、恢复与渲染服务契约

一个 exe 内置 worker，每 2 秒取任务，每进程串行处理一个任务；MySQL 内容锁原子领任务，租约 120 秒，每项执行前续租。运行记录、输出链接和额度都持久化。每轮自动尝试最多 3 次；429/503 按 5/10 秒延后重试，其他明确拒绝/坏数据终态失败。网络错误标记 upstream_delivery_unknown，不盲目自动重发。管理员/用户手工重试增加最多 3 次机会。

进程退出/崩溃遗留任务在租约过期后恢复，旧租约不能写输出或结算；已落库项目不重复上传。外部调用发送稳定的 Idempotency-Key（按任务 ID 和项目序号）。外部服务必须真正支持该键，才能消除响应丢失或崩溃窗口造成的重复生成/计费；不能据此宣称第三方调用恰好一次。取消仅取消本地后续提交，不保证中止远端已接收的生成，也不代表第三方费用已退。

renderer 是预留给公司受信渲染服务的适配器，本 exe **不内置 Chromium，也不原生渲染完整 Fabric**。其 POST 请求：

```json
{
  "schemaVersion": 1,
  "format": "png",
  "content": {"width":600,"height":800,"engine":"fabric","engineVersion":"6.7.1","schemaVersion":1,"document":{"objects":[]}},
  "resources": {"123":{"mime":"image/png","base64":"...","fontFamily":""}}
}
```

响应 `{"imageBase64":"..."}`。服务须按资源 ID 替换图片/字体、等待字体加载，使用隔离渲染环境，禁止任意网络访问，并实现幂等键。后端解码并校验 MIME、文件完整性、尺寸和存储额度后才接受结果。该服务未提供/未配置时批量渲染不可用，不能返回假成功。

常见任务 errorCode：provider_disabled、account_disabled、attempts_exhausted、upstream_busy、upstream_rejected、upstream_delivery_unknown、upstream_image_invalid、upstream_dimensions_invalid、renderer_format_invalid、renderer_input_too_large、execution_failed。管理员可查 attempts；errorCode 不包含上游原始响应或密钥。
