# AI 图片创作入口与服务配置

本阶段提供前台 AI 创作入口和 Vben 后台配置管理，不接入真实 AI 生图。

## 前台

首页搜索区域支持“搜索 / AI 生成”切换。用户填写不超过 2000 字符的描述，可选择一张 PNG/JPG/WebP 参考图（20 MB 以内，尺寸沿用现有编辑器限制）。未登录时显示登录框并保留输入。

进入后使用既有素材和作品接口创建草稿；有参考图时以原图尺寸打开，没有时创建 1024 × 1024 空白画布。编辑器默认打开 AI 创作面板，参考图可以切换到“编辑属性”操作。上传图不会冒充生成结果。

描述和服务选择仅存于当前标签页 sessionStorage（按作品 ID 隔离）；可“暂存描述”，刷新可恢复，不承诺跨设备或关闭标签页后保留。图片/画布由原有作品接口保存。

面板只调用 GET /api/v1/job-capabilities 读取已启用且有密钥的图片服务名称与模型，不接收服务地址或密钥。生成按钮禁用，始终显示“待接入”；不提交 POST /api/v1/jobs。

## 后台

地址：http://localhost:5666/design-providers ，菜单“AI 服务配置”。需要 provider:write 权限。

使用已有接口：
- GET /api/admin/v1/providers
- POST /api/admin/v1/providers
- PUT /api/admin/v1/providers/:id（携带 version，冲突后刷新重新编辑）

字段：服务名称、完整 HTTPS 接口地址、模型名称、API Key、配置启停。默认停用。编辑时密钥不回显；留空保留，输入新值替换，明确勾选可清除。后端既有 AES-GCM 加密存储、权限检查和审计保持不变。页面没有测试连接按钮，不发送外部服务请求。

启用配置可让前台读取服务名称，但不会开启本阶段前台的生图功能。既有任务执行模块保持原状，本次未添加或调用生成适配器；未来接入需单独验证服务协议、参考图输入和结果保存，不能承诺填写任意服务地址即可生成。

## 验证

前台与 Vben 后台类型检查、生产构建通过。Playwright 模拟后端验证参考图/纯文本入口、登录后保留输入、草稿刷新、无配置提示、后台新增/修改/清除密钥及版本提交。检查前台与后台本轮流程均无 jobs 请求。本轮未在实际数据库写入测试服务商配置，也未调用外部 AI。

本次无数据库迁移和 Go 代码变更，无需重启后端。刷新两个前端即可使用。
