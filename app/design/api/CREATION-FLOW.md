# 图片设计创建流程

## 前台

入口“创建”仅保留新增画布、导入图片、打开本地。

- 新增画布：输入名称与 px 宽高，或从服务端推荐尺寸中选择；提交后创建作品并进入 `/design/:id`。
- 导入图片：PNG/JPG/WebP，最大 20 MiB；校验解码后的宽高，上传为私有素材，按原图尺寸生成包含图片对象的作品。
- 打开本地：本站“保存到本地”导出的 JSON（format=huizuo-design、version=1、title、content），最大 5 MiB；另存为新作品，服务端再次验证文档及资源权限。暂不支持 PSD/yft 私有格式/自定义字体，引用素材需要在当前账号仍可访问。
- 所有创建需要登录，并携带幂等键；网络结果不确定时相同输入重试复用键与内容。图片上传成功后创建失败，素材仍可在“我的上传”管理。
- 新图片编辑页采用 Fabric 6，支持文字、矩形、图片添加与变换、删除选中对象、手动按版本保存、PNG 导出、本地 JSON 下载。保存冲突不会自动覆盖，提示先保存到本地。它是本阶段的基础编辑页，原 yft 完整编辑器保留在 `/editor`，复杂排版/滤镜/PSD 尚未接入。
- `/my` 使用独立路由，避免与首页 alias 相同导致点击“我的”或登录后跳转被判为重复导航。

## 后台

菜单“画布推荐尺寸”，地址 `/design-canvas-presets`。

- 新增、编辑名称/分类/宽高、启用停用、上移下移、移除，统一点击“保存配置”生效。
- GET `/api/v1/canvas-presets`：公开读取已启用的尺寸，按数组顺序展示。
- GET `/api/admin/v1/canvas-presets`：读取完整配置，需要 canvas:read。
- PUT 同地址：`{version,items:[{id,name,category,width,height,enabled}]}`，需要 canvas:write；事务更新并写入审计，版本冲突返回 409。
- 至多 100 项，单边 1–8192 px，总像素至多 4000 万；允许清空推荐列表，前台仍可自定义尺寸。
- 默认种子：手机海报、横版海报、小红书配图、公众号首图/次图、文章长图。不提供视频入口。

## 升级

数据库 schema 6，新增 006_canvas_presets.sql；不要修改已应用的旧迁移。停止旧后端后执行 migrate，再执行 serve。后台重新登录取得新增权限。

## 验证

隔离 MySQL 集成测试覆盖默认值、鉴权、停用隐藏、无效尺寸、乐观锁冲突和空列表；浏览器连接隔离 API 验证后台配置同步、创建/保存/重载、图片导入、设计 JSON 下载后重开、PNG 导出与 390px 窄屏布局。测试数据不写入本地 design 业务库。
